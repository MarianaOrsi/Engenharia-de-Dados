# 🚀 Engenharia de Dados — Faculdade

Repositório dedicado aos estudos, exercícios, projetos e experimentos desenvolvidos durante minha formação em **Big Data e Engenharia de Dados**.

O objetivo deste repositório é documentar minha evolução na área de Engenharia de Dados, reunindo conhecimentos práticos sobre **bancos de dados, pipelines, processamento, armazenamento, integração e arquitetura de dados**.

---

## 🎯 Objetivos

Durante a formação, este repositório será utilizado para:

* 📚 Registrar conteúdos e conceitos aprendidos em aula;
* 💻 Desenvolver exercícios e projetos práticos;
* 🔄 Construir pipelines de dados;
* 🗄️ Trabalhar com diferentes tipos de bancos de dados;
* ☁️ Explorar tecnologias de Big Data e Cloud;
* 🐳 Utilizar containers e ambientes isolados com Docker;
* ⚙️ Conhecer ferramentas utilizadas no mercado;
* 📈 Desenvolver projetos que possam compor meu portfólio profissional.
