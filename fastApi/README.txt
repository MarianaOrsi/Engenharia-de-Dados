# API de Estudos com FastAPI

API desenvolvida em Python utilizando FastAPI como parte dos estudos
em Engenharia de Dados.

## 🎯 Objetivo

O objetivo deste projeto é praticar o desenvolvimento de APIs REST
e compreender como uma API pode atuar como uma fonte de dados em
um pipeline de Engenharia de Dados.

## 🛠️ Tecnologias

- Python
- FastAPI
- Uvicorn
- Pydantic
- Git/GitHub
